## 🎮 玩法

### 一天 = 备菜 → 经营 → 夜晚 → 日结

| 阶段 | 内容 |
|------|------|
| 🌅 卯时备菜 | 从菜谱选 4 道上架、押份数、定价。押少缺货，押多腐坏 |
| 🏮 白天经营 | 3 时段 × 8 桌，**手动派餐**：客人「??? 口味成谜」，试菜扒出 TA 的三维偏好（口味/技法/食材） |
| 🌙 夜晚 | **搜打撤副本**（摸金校尉厨房版）：大本营 → 绿/黄/红三层热区 → 搜索摸食材 → 遭遇战 → 深入还是撤离 |
| 🌃 子时日结 | 说书人夜报：今日整体如何、谁满意谁不满、明日建议 |

### 核心系统

- **手动派餐 + 扒口味**：好评 → 这道菜的属性里藏着 TA 喜欢的；差评 → 全排除；正交试探收敛，同类只剩一个候选即确定偏好。配餐时限 1:30。
- **食物本体分**：食材稀有度（白→橙）+ 技法名菜匹配（四面体）+ 厨艺/见识/创造力 + 特殊描述 bonus
- **食客三维偏好**：口味（川菜 24 味型归 6 大类）× 技法 × 食材
- **料理的四面体**（玉村豊男《料理の四面体》）：火顶 + 水/油/空气底三角，三条技法线（煮线/炸线/烧线）+ 蒸汽/生领域——妙手偶得即"四面体创作"
- **搜打撤副本**：绿区保底收益 → 黄区稳定收益 → 红区高上限+Boss；撤离点既是安全承诺也是末局冲突
- **RPG 成长闭环**：白天利润 → 武馆买秘籍 / 拜师（好感≥40）/ 潜能修炼 → 战力↑ → 副本更深 → 稀有食材 → 菜单更强
- **主叙事 Terminal**：顶栏一键切换「📜 主叙事 / 🗔 外部 UI」。研发在说书人叙事里进行：`放料 X Y Z` → `技法 炖` → `开火`，AI 即兴起名
- **AI 分级**：⚙ 配置 OpenAI 兼容反代站后启用（敌人 AI 生成/研发 AI 起名/每日 AI 报告）；没配也能玩——白名单与模板兜底

## 🧭 界面

- **固定一屏**：不滚动，适配电脑屏幕
- **外部 UI**：备菜屏 / 8 桌看板（SLG 消息流+客人立绘+底部输入）/ 夜晚面板 / 日结
- **主叙事**：说书人终端（正文|角色|场景|表情），研发与对话走这里

## 📁 项目结构

```
src/
├── engine/           # 纯函数引擎（可测）
│   ├── data.js           # 31 食材（单价/稀有度/风物志）+ 技法（四面体）+ 10 菜谱
│   ├── guestEngine.js    # 16 熟客档案（三维偏好）+ 路人模板 + 种子生成
│   ├── dayEngine.js      # 白天：手动派餐 + 8 桌状态机 + 10 tick/时段
│   ├── tasteProbe.js     # 扒口味推理（候选/排除/正交收敛）
│   ├── dishScore.js      # 食物本体分 + 三维匹配分
│   ├── extractionEngine.js # 搜打撤：三层热区/搜索/遭遇/撤离
│   ├── battleEngine.js   # 回合制战斗（qucuo 模型简化版）+ 敌人白名单池
│   ├── aiEnemy.js        # AI 敌人生成（AI 填皮，数值系统裁决）
│   ├── aiDish.js         # AGI 出餐（AI 起名，喂食材风物志）
│   ├── aiClient.js       # OpenAI 兼容调用 + 降级
│   ├── dayReport.js      # 每日 AI 报告（模板兜底）
│   ├── terminalEngine.js # 主叙事命令路由
│   ├── kungfuData.js     # 武学/装备/拜师/修炼
│   └── economy.js / prepEngine.js / satisfaction.js
└── ui/                # React 界面
    ├── DevelopScreen.jsx   # 四面体研发台
    ├── ExtractionScreen.jsx# 搜打撤屏
    └── TerminalScreen.jsx  # 主叙事终端
```

## 🛠 技术栈

Vite + React + Vitest。引擎全部纯函数（种子确定性、零 AI 也能完整游玩），AI 是增味不是主料——三级降级：全 AI → 模板+记忆 → 纯白名单。
